# Minha Automação com Cypress

Este projeto utiliza o Cypress para automatizar os testes de uma funcionalidade de login e de atualização de usuário. O Cypress é um framework de testes end-to-end baseado em JavaScript que permite aos desenvolvedores escrever testes e executá-los em um navegador real.

## Instalação

```bash
npm install
```

>**NOTA:**
>
>É necessário ter o **Node** instalado.

## Execução

```bash
# Abrir a interface do Cypress
npx cypress open

# Executar a automação via linha de comando
npx cypress run
```
